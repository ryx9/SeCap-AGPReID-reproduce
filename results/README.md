# Result layout

- `video-demos/`: curated, shareable annotated demo videos and compact reports.
  MARS is the labelled cross-camera ReID demonstration; VisDrone is a separate
  detector/tracker validation demonstration.
- `secap-evaluation-v10/`: curated model-evaluation metrics and failure audits.
- `reproduction/`: compact training summaries and curves.
- `raw/`: local Kaggle downloads retained for provenance and intentionally not
  version-controlled.

Large archives are in `artifacts/archives/`, while model checkpoints remain in
`checkpoints/`. Neither is committed to Git.
